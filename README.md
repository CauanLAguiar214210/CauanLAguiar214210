## 🤖 IA + Obsidian

Utilizo **Obsidian como uma base de conhecimento técnico para documentação e organização dos projetos**.

A documentação estruturada no vault serve como **contexto para agentes de IA**, permitindo orientar ferramentas como:

`OpenCode` `Claude` `Qwen` `Antigravity CLI` `Qoder CLI` `ChatGPT` `Copilot`

O objetivo é manter informações sobre **arquitetura, decisões técnicas, regras de negócio, estrutura dos projetos, padrões e documentação** organizadas e reutilizáveis pelos agentes durante o desenvolvimento.
